## Quiet Recorder 목업

### 범위
- 상태: 설정 전 / 준비 완료 / 실행 중
- 테마: Light / Dark
- 총 6화면

### 설계 원칙
- 홈에는 현재 상태를 설명하는 메시지 1개와 주 행동 1개만 둔다.
- 완료된 인증·권한 목록과 최근 성공 상태는 반복 노출하지 않는다.
- 설정은 우측 상단의 별도 화면으로 이동한다.
- 카드·그림자 대신 여백과 얇은 선을 사용한다.
- Sage는 주 행동, Coral은 녹음·중지·오류에만 사용한다.
- Light의 Sage `#52746C`, Coral `#A4473F`는 작은 글자 대비 4.5:1 이상으로 보정했다.

### 인터랙션
- 설정 아이콘: 설정 화면 열기
- 설정 전/준비 완료 버튼: 상태 안내 토스트
- 실행 중 버튼: 중지 확인 패널
