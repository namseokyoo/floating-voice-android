# Floating Voice v0.6.4 — Connection Information and Anchored Settings Menu

## Scope

This candidate contains only the two requested UI changes:

1. Show saved Telegram connection information directly on the Telegram connection page.
2. Replace the settings bottom sheet with a standard popup menu anchored to the Home gear.

No routing, authentication, recording, target-replacement, or session-persistence behavior is intentionally changed.

## Telegram connection page

- Keeps the current Telegram authentication state at the top.
- Shows the stored Telegram API ID.
- Shows the API Hash with only its final four characters visible.
- Shows the stored Telegram account phone number without claiming the session is ready.
- Keeps **Log out of Telegram / Revoke session** as the separate destructive action below a divider.
- Removes the extra API-information navigation button.
- Shows localized “Not saved” values when no valid connection configuration exists.

## Settings menu

- Home gear opens an Android `PopupMenu` anchored to the gear.
- Menu-specific English labels stay short enough for large-font popup rows.
- The menu contains exactly three routes:
  - `App` → App settings
  - `Destination` → Transfer destination
  - `Telegram` → Telegram connection
- No bottom sheet or settings landing/dashboard is used.

## User-operated device checks

1. Update-install over v0.6.3 without uninstalling.
2. Open Home and tap the gear; confirm the list opens beside/below the gear rather than from the bottom.
3. Confirm all three menu items open their existing separate pages.
4. Open Telegram connection and confirm status, API ID, masked API Hash, and phone number appear directly.
5. Confirm API Hash exposes only its final four characters.
6. Confirm logout/session revoke remains below the connection information and still requires confirmation.
7. Confirm Back returns to Home and existing Telegram session/target remain unchanged before logout.
8. Repeat with Korean/English and large font.

Real-device installation and interaction remain user-operated.
