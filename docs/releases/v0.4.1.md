## Changes from v0.4.0

- Adds the first long-term release-signed GitHub APK.
- Publishes the signing-certificate fingerprint and artifact checksum.
- Updates privacy, security, contribution, and distribution documentation for binary delivery.
- Prevents Android Autofill from offering to retain the Telegram account phone and fixed-target username fields.
- Keeps the Korean/English UI, fixed-bot verification, OGG/Opus recording, success-only deletion, and locale-state ordering from v0.4.0.

## Installation and update warning

This is a sideloaded GitHub release, not a Play Store app. Android may require permission to install unknown apps.

A debug-signed build and this release APK use different signing certificates. Android cannot update one over the other. If a debug build is installed, uninstalling it before installing v0.4.1 will delete that app's local settings, Telegram session, and retained recordings. Future official releases signed with the fingerprint above can update v0.4.1 without that signature migration.

## Known limitations

- No Play Store or AAB distribution
- `arm64-v8a` only; 32-bit devices and x86 emulators are unsupported
- Each user must provide their own Telegram API ID and API Hash
- Public bot username targets only
- No one-tap deletion of every local setting, session, and retained recording
- Failed recordings remain as unencrypted OGG files in app-specific storage

Floating Voice is an independent, unofficial project and is not endorsed by Telegram.
