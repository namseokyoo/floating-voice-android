# Floating Voice v0.5.0 — Final device-test candidate

Floating Voice `v0.5.0` adds safe cancel, reducer-backed overlay interaction, Material 3 controls, fixed-target text sending, a floating text composer, selectable overlay sizing, and a state-centered main dashboard.

This candidate has the same package and signing certificate as the official `v0.4.1` APK, with a higher version code, so Android can accept it as an update. Actual installation/update behavior remains user-device validation until explicitly reported PASS.

## Changes from v0.4.1

- Adds reducer-backed tap, drag, long-press, stale-callback, and teardown handling.
- Adds explicit cancel that never sends and keeps stop/send distinct by position, shape, label, and accessibility semantics.
- Adds Material 3 idle FAB, recording dock, and a shallow labeled action palette.
- Adds persisted Small/Medium/Large floating-button sizes.
- Keeps stop/send centered on the former bubble anchor at both screen edges; cancel stays opposite.
- Adds a translucent, task-isolated text composer with in-memory rotation recovery and acknowledged app-scoped handoff.
- Sends plain text only to the currently verified fixed Telegram target and tracks TDLib queued/final success/failure without automatic fallback.
- Adds process-durable temporary text-message ID classification without persisting composer text bodies.
- Reworks the main screen into a Material 3 readiness dashboard with light/dark support and dashboard-only dynamic color. Overlay and composer surfaces retain fixed semantic tokens, including recording red.

## Required final verification

The final candidate is built only after this source is committed and pushed. The delivery record must contain the exact byte size and SHA-256 plus evidence for clean tests, zero lint errors, localization parity, v2/v3 signature coverage, certificate continuity with `v0.4.1`, ZIP/ELF 16 KB alignment, production manifest metadata, arm64-only native contents, packaged credential/private-path scans, and artifact freshness.

## User-operated final device validation

1. Update-install over the official `v0.4.1` APK without uninstalling.
2. Confirm the Telegram session, encrypted setup, target, language, and button-size preference remain available.
3. Confirm the dashboard accurately shows setup-needed, ready, and running states.
4. Test Small/Medium/Large sizes and left/right screen edges.
5. Test voice success, failure behavior if available, and X cancel with no Telegram delivery.
6. Long-press, open the text composer, send text, and verify it reaches the fixed target.
7. Close/back from the composer and confirm no message is sent.
8. Rotate or change locale with a draft and confirm the in-memory draft remains.
9. Stop the floating service and confirm the overlay/composer close without an unexpected send.
10. Check Korean/English, dark mode, large font, and TalkBack labels as practical.
