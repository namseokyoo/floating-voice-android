# Floating Voice v0.6.1 — Overlay brand + safe-area candidate

Floating Voice `v0.6.1` keeps the Quiet Recorder information architecture and aligns the floating control with the launcher icon while hardening system-bar safety.

## Candidate contract

- Package: `com.sidequestlab.floatingvoice`
- Version: `0.6.1` (`versionCode 11`)
- Android: 10+ (`minSdk 29`, `targetSdk 36`)
- ABI: `arm64-v8a` only
- APK signature schemes: v2 and v3
- Signing certificate SHA-256: `FD:97:82:9D:19:F8:B0:57:5B:79:EC:1E:8B:7A:26:16:A0:69:7C:EE:86:5D:29:B0:B5:28:78:3C:39:88:AB:A6`

Exact filename, byte size, SHA-256, and build time are recorded with the delivered binary after the clean commit-bound build.

## User-visible changes

- Idle floating button is circular and reuses the launcher mic-and-wave foreground artwork.
- Default floating-button Sage is exactly the launcher background `#52746C` in Light and Dark modes.
- Settings now places floating-button color directly after size with Sage, Ocean, Violet, and Amber presets.
- Color changes apply to the running idle bubble; recording/stop/error red remains fixed.
- Main Activity applies status-bar, navigation-bar, and display-cutout insets to prevent top/bottom clipping.
- Service overlays use current window metrics and one safe rectangle for idle, drag, recording dock, and action palette placement.

## User-operated device validation

1. Update-install over v0.6.0 without uninstalling, then launch the app.
2. Confirm the retained Telegram target, permissions, language, size, and other settings are still present.
3. Confirm the title/settings icon are fully below the status bar.
4. Confirm the bottom primary action remains fully above gesture or three-button navigation.
5. Tap the home primary action to start the floating button.
6. Drag the idle bubble to all four edges and confirm it cannot enter system bars or a display cutout.
7. Open Settings and change Small/Medium/Large and each of the four colors; confirm the running idle bubble updates.
8. Confirm the default Sage button visually matches the launcher icon background and uses the same mic-and-wave symbol.
9. Start a recording and confirm the recording dock stays fixed red regardless of the selected idle color.
10. While idle and while recording, rotate or change navigation mode if available; confirm the visible control immediately returns inside the safe area and recording continues.
11. Send one voice and one text message to confirm transport behavior is unchanged.
