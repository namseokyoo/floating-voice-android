# Floating Voice v0.6.0 — Quiet Recorder device-test candidate

Floating Voice `v0.6.0` replaces the settings-heavy main dashboard with the approved Quiet Recorder information architecture.

- Version: `0.6.0` (`versionCode 10`)

- ABI: `arm64-v8a` only

Exact filename, byte size, SHA-256, and build time are recorded with the delivered binary after the clean commit-bound build.

## User-visible changes

- Home shows one state message and one primary action for connection, authentication, target, permissions, ready, and running states.
- Telegram setup is a resumable four-step flow: API/account information → authentication → destination → permissions.
- Language, floating-button size, API information, and logout move to Settings.
- Successful status messages are transient; errors and retained-file evidence remain visible.
- Removes activity Dynamic Color and the purple/card-heavy dashboard.
- Adds deterministic Light/Dark warm-neutral, Sage, and Coral tokens with accessible text contrast.
- Preserves the existing verified-target, foreground-service, recording retention, cancel, text composer, and overlay behavior.

## User-operated device validation

1. Update-install over the delivered v0.5.0 candidate without uninstalling.
2. Confirm the existing Telegram session, target, language, and button-size preferences remain available.
3. Check Home in setup/auth/target/permission/ready/running states; each state should show one primary action.
4. Open Settings and verify language, button size, API information, and logout are reachable.
5. Revoke microphone permission and confirm Home does not continue claiming Ready or Running.
6. Check Light/Dark mode and large text for clipping.
7. Start and stop the floating button; confirm the stop dialog appears and Telegram remains connected.
8. Send one voice and one text message to the fixed target; confirm no automatic fallback.
9. If a send failure is available, confirm the error/retained-file notice remains visible.
