# Floating Voice v0.4.0 — Source release

Floating Voice is an Android 10+ floating OGG/Opus voice recorder that sends a voice note through the signed-in user's Telegram account to one verified bot target using TDLib.

## Highlights

- Korean and English UI
- System-default, 한국어, and English app-language options
- Android 13+ per-app language integration and Android 10–12 AppCompat persistence
- Image-only floating microphone and stop controls
- Fixed bot-target verification immediately before sending
- Recording deletion only after `UpdateMessageSendSucceeded`
- Locale-refresh ordering and foreground-notification state fixes
- Apache License 2.0, privacy notice, security policy, and contribution guide

## Source-only distribution

This release intentionally has **no APK or AAB asset**. GitHub provides the source ZIP/TAR for this tag. Generated TDLib Java/JNI artifacts, signing keys, Telegram sessions, recordings, and local build output are not included.

## Build prerequisites

- JDK 17
- Android SDK 36
- Android NDK `28.2.13676358`
- Docker for the documented TDLib bootstrap
- `arm64-v8a` Android 10+ device

Prepare TDLib from commit `022d60202e446ad1287b9fb68e687c8a0760788b` and build:

```bash
./scripts/build-tdlib-docker.sh
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
./gradlew clean test lintDebug assembleDebug
```

See [README.md](https://github.com/namseokyoo/floating-voice-android/blob/v0.4.0/README.md), [README.en.md](https://github.com/namseokyoo/floating-voice-android/blob/v0.4.0/README.en.md), [PRIVACY.md](https://github.com/namseokyoo/floating-voice-android/blob/v0.4.0/PRIVACY.md), and [SECURITY.md](https://github.com/namseokyoo/floating-voice-android/blob/v0.4.0/SECURITY.md) before use.

## Known limitations

- No official binary distribution or release-signing key
- `arm64-v8a` only
- Public bot username targets only
- No one-tap deletion of every local setting, session, and retained recording
- Failed recordings remain as unencrypted OGG files in app-specific storage

Floating Voice is an independent, unofficial project and is not endorsed by Telegram.
